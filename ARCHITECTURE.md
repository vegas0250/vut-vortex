# Архитектура Vortex

Vortex — приложение VUT. Оно не платформа интерфейса и не общий каркас для всех будущих инструментов.

```text
Visual / UI system     → VUI
Application capability → этот репозиторий
Desktop / OS           → Electron, только main и preload
OS-specific behavior   → src/main/platform
```

## Что принадлежит VUI

Тема, плотность, оболочка, панель команд, таблица, диалог, поле, переключатель, хлебные крошки, навигация, свойства, пустое состояние, фокус, клавиатура таблицы и множественный выбор.

`vui-data-grid` начиная с версии 1.1.0 сам ограничивает число DOM-узлов. Vortex передаёт строки и читает `selectedIds`. Он не рисует свою таблицу.

Локальный `src/renderer/styles.css` задаёт только высоту окна и колонки списка. В нём нет цветов, шрифтов и отступов дизайн-системы.

## Что принадлежит Vortex

- чтение каталога и метаданных;
- корни файловой системы и стандартные папки;
- история навигации;
- создание, переименование, копирование, перемещение, удаление;
- скрытые имена;
- команды приложения (`go.back`, `file.delete` и остальные) через `CommandRegistry` из VUI.

Идентификатор строки — абсолютный путь. Что он значит, решает Vortex. VUI хранит только выбор.

## Electron

```text
Main        окно, диалог ОС не нужен файловому менеджеру, filesystem, IPC
Preload     contextBridge: list, locations, mkdir, rename, remove, copy, move, open
Renderer    без Node и без Electron
```

`nodeIntegration` выключен. `contextIsolation` и `sandbox` включены. Production получает CSP. Переходы за пределы приложения и `window.open` запрещены.

В runtime-пакет не входят исходники, тесты, карты, devDependencies и `node_modules`. VUI уже вшит в renderer, поэтому `beforeBuild` возвращает `false`: иначе electron-builder положит в asar всё дерево `vui`, включая полный `lucide`. Renderer собирается одним модулем из точечных импортов `vui/*`.

## Платформа

Единственная развилка `process.platform` — `platform()`. Дальше код вызывает `PlatformAdapter`: скрытые имена, список дисков, домашние каталоги. Бизнес-операции копирования и навигации этой развилки не содержат.

Windows x64 и Linux x64 — цели упаковки. Код приложения от архитектуры процессора не зависит.

## Чего здесь нет намеренно

Общего пакета VUT, плагинов, FTP, SFTP, SSH, терминала, торрентов, своего дизайн-системы и монорепозитория с VUI или Archive. Archive — другой репозиторий. Vortex его не импортирует.

Новый источник файлов позже реализует тот же результат `DirectoryPage`. Он не должен знать про таблицу, а таблица не должна знать про источник.
